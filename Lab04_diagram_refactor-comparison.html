What I'd do differently: one hardcoded line

A two minute change that turns a file written for one person into a file a team can reuse.

This lab, as written 
resource "azurerm_resource_group" "rg" {
  name = "rg-lab04-tf-giovanni"
  location = "East US"
}

Works fine solo. Breaks the moment a second person reuses this exact file, since the name is baked in.

One variable added 
variable "your_name" {
  type = string
}

resource "azurerm_resource_group" "rg" {
  name = "rg-lab04-tf-${var.your_name}"
  location = "East US"
}

The configuration file never changes again. Only a separate variables file does, per person or per environment.
